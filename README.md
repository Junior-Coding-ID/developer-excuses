## The excuse

> The checkout passed every test, but in production customers started buying two things at once, which was not part of our company's understanding of shopping.

## How it works

`main.ts` writes the excuse above, exactly as-is plus a trailing newline,
to `entry.txt` inside the output directory (`$MAKEFUN_OUTPUT`, default `/output`).

```sh
node main.ts
```
